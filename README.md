# 清邁慢旅｜2026 旅行手帳

2026/11/15–11/22清邁八日互動行程，手機與桌機皆可使用。根目錄index.html為完整網頁，不需套件或API金鑰。

## 功能

- 依Asia/Bangkok日期自動換日，每30秒及返回頁面時檢查。旅程前顯示首日、結束後顯示末日。
- 可手動選日；按「跟隨今天」恢復自動模式。
- Google Maps內嵌地點標記、步行/搭車導航、每日分段路線。
- 經使用者允許後取得定位，顯示座標、精度與到景點的約略直線距離。
- 所有地點搜尋與行程完成勾選。
- 畫面底部常駐「今日住宿」列：依泰國日期顯示當晚飯店、與目前位置的直線距離，一鍵看地圖或導航回飯店；11/18起自動改為Arun Khiri並標示換飯店，11/22標示退房日。
- 「◎ 附近」：定位後自動彈出500公尺內的景點寺廟、餐廳、咖啡甜點、市集購物、按摩，★為本行程推薦；按名稱即開Google Maps步行導航，「評論」連到Google地點頁看評分。清邁行程範圍內使用打包的OpenStreetMap資料（nearby.json，可離線、不送出座標），範圍外才即時查詢Overpass。重建資料：見tools/build_nearby.py。
- 地點介紹：行程地點按「地圖標記」後，地圖下方顯示景點／餐廳介紹與行程備註；附近清單按「介紹 ▾」展開——行程地點用本頁撰寫的介紹，其他地點顯示維基百科摘要（有條目時，連線載入）、OpenStreetMap說明、料理類型與營業時間（中文化），並附步行導航與Google評論・照片。
- 📷 照片打卡：拍照或從相簿加入，依「照片GPS → 足跡紀錄（前後2分鐘）→ 拍攝當下定位」決定地點，自動配對150公尺內最近的行程景點或店家；每張照片可開Google Maps地點／精確拍攝點、改地點、存到手機（分享選單）、刪除。照片也以縮圖顯示在「我的旅行足跡」地圖上，並可匯出KML匯入Google我的地圖。照片只存在此瀏覽器的IndexedDB。
- 旅程當天自動標示「● 現在」與「下一站」，每30秒更新。
- 可加到主畫面；首次連線後離線仍能開啟行程與已存紀錄（Google地圖、導航與底圖仍需網路），離線時頂端顯示提示。

## 定位與距離

定位需在HTTPS網站開啟並允許位置權限；內嵌預覽可能不支援。一般定位只在記憶體中使用，不回傳網站；主動開啟旅行足跡後，軌跡會保存在手機瀏覽器。Google Maps相關按鈕會將所需座標傳給Google；勾選紀錄僅存在目前瀏覽器。

距離由裝置位置和景點概略座標計算，為直線估算，非道路里程、步行時間或入口精準距離。請以Google Maps具名地點、分店和實際導航為準。

## 我的旅行足跡（V2）

1. 手機開啟HTTPS網站，切換「我的旅行足跡」。
2. 按「開始記錄」，允許位置權限，等待可靠定位。
3. 可暫停、繼續或結束；依泰國日期保存並查看路線。
4. 每天匯出GPX或GeoJSON備份。重新整理後保留歷史，但不會自動恢復錄製。

軌跡只保存於此手機瀏覽器localStorage，不上傳完整軌跡；清除網站資料、無痕模式或換裝置可能失去紀錄。底圖為Leaflet 1.9.4與OpenStreetMap，需要網路；底圖服務會收到IP和地圖區域請求。Google Maps景點和導航維持原功能。

累積距離包含步行與搭車，為GPS點之間的距離估算。略過小幅漂移、精度超過65公尺與不合理跳點；暫停、跨午夜、背景切換、定位失敗或超過2分鐘的間隔分段，不補畫未知路線。各日期最多30,000點，儲存失敗時停止收集並提示匯出。

記錄中會請求螢幕常亮（Screen Wake Lock，支援的瀏覽器才有效），減少自動鎖屏中斷。網頁仍不能保證鎖屏或背景持續定位；請保持前景開啟，全天可靠記錄仍應使用有背景定位權限的手機App。

已新增模擬測試：開始/暫停/結束、過濾誤差與跳點、跨日分段、定位中斷、歷史還原、儲存失敗回復、定位拒絕、過期回呼忽略及兩種匯出。尚未以實體手機全天測試。
